# Smart Personal Firewall (IDS + IPS Hybrid)

Python-based smart firewall built using Scapy.

## Features

- Port Scan Detection
- SYN Flood Detection
- Packet Flood Detection
- Automatic IP Blocking
- Temporary Ban → Permanent Ban
- Colored Alerts
- File Logging
- Real-time Packet Monitoring
- Whitelist Support

## Requirements

Python 3.x

Install dependencies:

pip install -r requirements.txt

## Run Firewall

sudo python3 firewall.py
